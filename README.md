# SakhiSetu

SakhiSetu is a premium, production-ready Self Help Group Management System designed for NGOs, banks, government agencies, and rural community organizations.

## Stack
- Frontend: React + Vite + Framer Motion + Lucide Icons
- Backend: Express + MongoDB + JWT + Mongoose

## Run locally
1. Install dependencies: `npm run install:all`
2. Start the application: `npm run dev`
3. Frontend: http://localhost:5173
4. Backend: http://localhost:5000

## Included experience
- Premium landing page
- Dashboard overview
- Members, savings, loans, meetings, reports, and analytics modules
- Authentication screens and secure API infrastructure
